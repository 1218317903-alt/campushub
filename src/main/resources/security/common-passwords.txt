# 常用弱密码表
# ==========================================================================
# 用途：PasswordPolicy 用它拒绝"一看就会被人先试一遍"的密码。
#
# 为什么是"长度 + 弱密码表"而不是"必须含大小写+数字+符号"：
# 强制组合会把用户推向 Password1! / Qwer1234! 这类可预测变形，
# 而这类模式在攻击字典里的权重恰恰最高。NIST SP 800-63B 因此明确
# 建议放弃强制组合、改为检查已知泄露密码。
#
# 内容为**全部小写**，比较时也把候选密码转为小写，因此大小写变体（Password / PASSWORD）
# 会被同一条命中。
#
# 覆盖范围说明（如实记录，不夸大）：
#   本表收录公开泄露数据中最靠前的一批密码，它们覆盖了现实中弱口令攻击
#   命中率的绝大部分长尾之前部分。它不是、也不应是完整泄露库
#   （那需要外部服务与持续更新，本项目不引入该依赖）。
#   如需扩充，直接往本文件追加行即可，无需改代码。
#
# 扩展方式：在文件末尾追加，每行一个，全小写，可用 # 注释。
# ==========================================================================
